# Дослідження системного переривання int 0x80

## 1. Визначення
`int 0x80` — це інструкція асемблера для архітектури x86 (32-біт), що генерує програмне переривання. У Linux воно використовується для здійснення **системних викликів** (syscalls) — звернень програми до ядра ОС.

## 2. Передача параметрів (Дискусія)
При використанні `int 0x80` параметри передаються через регістри:
- **EAX**: Номер системного виклику (яку функцію виконати).
- **EBX, ECX, EDX, ESI, EDI**: Аргументи для цієї функції.
- **EAX (після виклику)**: Результат виконання.

## 3. Список основних системних викликів

| EAX | Назва | EBX (Arg 1) | ECX (Arg 2) | EDX (Arg 3) | Опис |
|:---:|:---|:---|:---|:---|:---|
| **1** | `sys_exit` | Код виходу | - | - | Завершення програми |
| **3** | `sys_read` | Дескриптор (0 для stdin) | Буфер | Кількість байт | Читання |
| **4** | `sys_write`| Дескриптор (1 для stdout)| Буфер | Кількість байт | Виведення |
| **5** | `sys_open` | Шлях до файлу | Прапорці | Права доступу | Відкриття файлу |

## 4. Висновок
Хоча в сучасних 64-бітних системах частіше використовується інструкція `syscall`, переривання `int 0x80` залишається фундаментальним для розуміння роботи Linux на 32-бітних архітектурах.
